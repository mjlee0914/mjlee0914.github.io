![alt text](image-1.png)

- count(특정 열): NULL값 제외한 행 개수만 셈
  

[group by 주의사항]
![alt text](image-2.png)
- SELECT에 집계함수 들어갈 때는 GROUP BY에 기준열 그룹화 꼭 해야함
- -> 집계함수는 행을 압축, 기준열은 행을 있는 그대로 반환하기 때문에 기준열도 GROUP BY로 압축해야 함
- SELECT에 집계함수 아닌 열이 있으면 그 열은 반드시 GROUP BY에 들어가야 함

## 테이블 결합
- `union`: 테이블 중복 없이 결합
- `union all`: 테이블 중복 포함 결합
- union -> 테이블 쌓기 (같은 형태의 데이터를 위아래로 쌓기)
- join -> 서로 다른 테이블 양옆으로 붙이기, 중복 컬럼 기준
  - `inner join`: 교집합, 두 테이블에서 ON 조건 일치하는 행만 포함
  - `기준테이블 lett join`: 기준테이블 행 전부 + 오른쪽 테이블에서 일치하는 행만 포함
  - `right join 기준테이블`: 기준테이블 행 전부 + 왼쪽테이블에서 일치하는 행만 포함
  - `full outer join`: 양쪽 테이블 일치 안해도 포함
  - `on`: 어떤 열 기준으로 연결할지 조건 (pk-fk 연결 방식)
