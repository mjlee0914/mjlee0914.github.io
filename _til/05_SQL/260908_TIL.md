EXISTS/NOT EXISTS in Subquery
![alt text](image-7.png)
- 값 하나라도 일치하면 TRUE 반환 = outer query 행 반환
- 아무것도 일치하지 않으면 반환 x
- SELECT 1은 관례적 표현
- 데이터가 존재하는지만 여부 판단할 때 사용
- 데이터가 많을 때 IN/NOT보다 효과적
