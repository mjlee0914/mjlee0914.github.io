## Mock page practice

오늘은 Sparta Club 강의 목록 페이지를 참고해서 mock page를 만들었다.

연습한 파일:
- HTML: [`mock-page/all_lecture.html`](../mock-page/all_lecture.html)
- CSS: [`mock-page/css/style.css`](../mock-page/css/style.css)

이번 연습에서 정리한 것:
- HTML 구조를 `header`, `nav`, `main`, `section`, `article`, `footer`로 나누기
- 별도 CSS 파일을 연결해서 레이아웃과 색상 관리하기
- `flex`, `grid`를 사용해서 강의 카드와 혜택 카드를 배치하기
- 이미지, 비디오, 버튼을 실제 페이지처럼 보이게 정리하기
- 이전에 HTML 안에 있던 스타일을 `css/style.css`로 분리하기
