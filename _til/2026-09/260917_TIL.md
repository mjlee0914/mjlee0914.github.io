## Today at a glance

오늘은 HTML 문서의 기본 구조와 CSS 전역 설정을 정리하고, Flexbox와 Grid로 레이아웃을 구성하는 방법을 연습했다. 마지막으로 shop 화면의 기본 골격도 만들었다.

이번 연습에서 정리한 것:

- HTML의 `head`에서 문자 인코딩, 반응형 viewport, 외부 CSS·아이콘·favicon을 연결한다.
- `:root`에는 반복해서 쓸 색상, 글꼴, 레이아웃 크기를 CSS 변수로 정의한다.
- `*` 선택자와 태그 선택자로 박스 크기·글꼴·기본 여백을 일관되게 초기화한다.
- Flexbox는 한 방향의 정렬, Grid는 행과 열을 함께 다루는 격자 레이아웃에 적합하다.

## 1. HTML document structure

shop 예제는 `head`에서 기본 메타 정보와 외부 리소스를 연결하고, `body`를 `header`, `main`, `footer`로 나눴다. 화면 아이콘은 외부 아이콘 CSS를, 사이트 아이콘은 favicon 파일을 사용했다.

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link rel="stylesheet" href="css/style.css">
  <link rel="icon" href="assets/favicon.ico">
</head>
<body>
  <header>...</header>
  <main></main>
  <footer></footer>
</body>
```

## 2. CSS reset and `:root`

전역 CSS는 브라우저마다 다른 기본 여백과 목록 모양을 먼저 정리한다. `:root`의 사용자 정의 속성은 글꼴, 색상, 레이아웃의 기준값을 한 곳에서 관리하게 해 준다.

```css
:root {
  --primary-font-family: 'Orbit';
  --primary-font-size: 13px;
  --primary-font-color: #313131;
  --primary-layout-size: 727px;
  --primary-layout-min-size: 320px;
}

* {
  box-sizing: border-box;
  font-family: var(--primary-font-family);
}

ul, ol, dl, dt, dd {
  margin: 0;
  padding: 0;
  list-style: none;
}
```

`*`는 모든 요소에 적용하는 전체 선택자다. 프로젝트에서는 `box-sizing: border-box`처럼 반드시 공통이어야 하는 규칙에만 사용하고, 세부 스타일은 태그·class 선택자로 나누는 편이 관리하기 좋다.

## 3. CSS selectors and basic styling

- 선택자는 `*`, 태그, class, id부터 시작하며, 일반적인 우선순위는 태그 < class < id < 인라인 스타일이다.
- 하위·자식·형제 선택자와 `:hover`, `:focus`, `:nth-child()` 같은 가상 클래스도 연습했다.
- `@import`와 `@font-face`로 웹 폰트·로컬 폰트를 연결하고, `font-display: swap`으로 로딩 중에도 텍스트가 보이게 했다.
- `box-sizing`, `margin`, `display`, `overflow`, `border`, `background`, `position`으로 요소의 크기·흐름·표시 위치를 제어했다.

## 5. Flexbox

`display: flex`는 부모 요소에 설정하고, 방향·공간 배분·교차축 정렬을 통해 자식 요소의 위치를 제어한다.

- `flex-direction`: `row`, `row-reverse`, `column`, `column-reverse`
- `justify-content`: 주축의 남은 공간 배분
- `align-items`: 교차축 정렬
- `flex-grow`, `flex-shrink`, `flex-basis`: 자식 요소의 남는 공간 배분, 축소, 기본 크기
- `flex-wrap`: 너비가 부족할 때 다음 줄로 넘길지 결정

## 6. CSS Grid

Grid는 행과 열을 동시에 다루는 2차원 레이아웃이다. `grid-template-columns`에 고정 너비나 `fr` 단위를 사용하고, `repeat()`으로 반복 패턴을 간단히 만들 수 있다. `gap`, `grid-row`, `place-items`로 카드 간격·차지 영역·정렬도 제어했다.
