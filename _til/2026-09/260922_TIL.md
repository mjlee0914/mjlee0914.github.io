## 실습과제: JavaScript 기초 문법 (4장 2강)

오늘 `ax_study`의 `chapter04/02.ipynb`를 따라 JavaScript의 변수 선언부터 조건문, 반복문, 예외 처리까지 복습했다. JavaScript는 같은 코드를 작성해도 **어떤 선언 키워드를 쓰는지**, **값과 타입을 어떻게 비교하는지**에 따라 결과가 달라질 수 있어 각 문법의 역할을 분명히 구분하는 것이 중요했다.

### 1. `var` 대신 `let`, `const` 사용하기

초기의 JavaScript에서는 `var`로 변수를 선언했다. 하지만 `var`는 선언 전에 접근해도 동작하는 것처럼 보이는 호이스팅, 선언 키워드를 빼먹었을 때 전역 변수가 되는 문제, 함수 단위 스코프 문제를 가지고 있다.

```js
var i = 10000;

for (var i = 0; i < 10; i++) {
  console.log(`for문에 정의된 i: ${i}`);
}

console.log(i); // 10
```

반복문 안에서 `var i`를 다시 선언했지만, `var`는 블록이 아니라 함수 단위로 범위를 가지므로 반복문 밖의 `i`도 바뀐다.

```js
let i = 10000;

for (let i = 0; i < 10; i++) {
  // 반복문 안에서만 사용하는 i
}

console.log(i); // 10000
```

`let`은 `{ }` 블록 안에서만 유효하므로 바깥의 `i`를 보호할 수 있다. 기본적으로는 재할당하지 않을 값에 `const`를 먼저 쓰고, 값 변경이 꼭 필요할 때만 `let`을 쓰는 습관을 들이는 것이 좋다.

```js
let score = 100;
score = 200; // 가능

const name = "mj";
// name = "minji"; // TypeError: const는 재할당 불가
```

### 2. 자료형과 `typeof`

JavaScript의 대표적인 자료형에는 숫자(`number`), 문자열(`string`), 불리언(`boolean`), `undefined`, `null`이 있다. `typeof`를 사용하면 현재 값의 자료형을 확인할 수 있다.

```js
const num = 100;
const text = "ABC";
const isReady = true;
let value;

console.log(typeof num);     // "number"
console.log(typeof text);    // "string"
console.log(typeof isReady); // "boolean"
console.log(value);          // undefined
console.log(typeof value);   // "undefined"
```

`null`은 **의도적으로 값이 없음을 표시한 값**이고, `undefined`는 **아직 값이 할당되지 않은 상태**다. 한 가지 주의점은 오래된 JavaScript 설계 문제 때문에 `typeof null`의 결과가 `"object"`라는 것이다.

```js
console.log(typeof null); // "object"
```

### 3. 템플릿 리터럴로 문자열 만들기

문자열과 변수를 이어 붙일 때 `+`를 사용할 수 있지만, ES6의 템플릿 리터럴을 쓰면 더 읽기 쉽다. 백틱 문자로 감싼 문자열 안에서 `${변수}` 형태로 값을 넣는다.

```js
const num1 = 10;
const num2 = 20;

const result = `${num1} + ${num2} = ${num1 + num2}`;
console.log(result); // 10 + 20 = 30
```

### 4. Truthy, Falsy와 기본값

조건문에서는 `false`뿐 아니라 `0`, 빈 문자열(`""`), `null`, `undefined`, `NaN`도 거짓처럼 처리된다. 이런 값을 Falsy라고 한다.

`||`는 왼쪽 값이 Falsy이면 오른쪽 값을 사용한다. 다만 `0`도 Falsy이므로, `0`을 유효한 값으로 남기고 싶을 때는 `??`를 사용해야 한다.

```js
let count = 0;

console.log(count || 10); // 10: 0도 Falsy로 판단
console.log(count ?? 10); // 0: null, undefined일 때만 10 사용
```

### 5. `==`보다 `===`으로 비교하기

`==`는 값이 같아 보이면 자료형을 변환해서 비교할 수 있다. 반면 `===`는 값과 자료형이 모두 같아야 `true`다. 예상하지 못한 자동 형변환을 막기 위해 `===` 사용이 권장된다.

```js
console.log(1 == "1");  // true
console.log(1 === "1"); // false
```

### 6. 조건문과 반복문의 실행 흐름

삼항 연산자는 간단한 조건을 한 줄로 표현할 때 사용할 수 있다.

```js
const num = 10;
const message = num === 10 ? "숫자가 10입니다." : "숫자가 10이 아닙니다.";

console.log(message);
```

`for`문은 정해진 횟수를 반복할 때 유용하다. 실행 순서는 **초기값 설정 → 조건 확인 → 본문 실행 → 증감식 실행 → 다시 조건 확인**이다.

```js
let total = 0;

for (let num = 1; num <= 100; num++) {
  total += num;
}

console.log(`합계: ${total}`); // 5050
```

`break`는 반복을 즉시 끝내고, `continue`는 현재 순서만 건너뛴 뒤 다음 반복을 진행한다. `switch`에서는 `break`가 없으면 다음 `case`까지 계속 실행되는 fall-through가 일어나므로 의도한 위치에 넣어야 한다.

### 7. 오류가 나도 흐름을 관리하는 `try...catch...finally`

실행 중 오류가 날 수 있는 코드는 `try` 안에 작성한다. 오류가 발생하면 `catch`에서 오류 정보를 받아 처리하고, `finally`는 성공·실패와 관계없이 항상 실행된다.

```js
try {
  let text;
  console.log(text.toUpperCase());
} catch (err) {
  console.error(err.name);    // TypeError
  console.error(err.message); // 오류 설명
} finally {
  console.log("무조건 실행");
}
```

## Object란?

객체(Object)는 관련 있는 데이터와 기능을 하나로 묶는 **이름표가 있는 수납함**처럼 볼 수 있다. 객체 안의 데이터는 프로퍼티(property), 객체 안에서 실행할 수 있는 함수는 메서드(method)라고 한다.

```js
const person = {
  name: "mj",            // 프로퍼티: key와 value 한 쌍
  nationality: "Korea",
  profession: "Software Engineer",
  introduce() {           // 메서드
    console.log(`My name is ${this.name}.`);
  }
};

console.log(person.name); // "mj"
person.introduce();       // "My name is mj."
```

여기서 `this`는 메서드를 호출한 현재 객체인 `person`을 가리킨다. 따라서 `this.name`은 `person.name`과 같은 값을 읽는다.

객체의 프로퍼티는 점 표기법 또는 대괄호 표기법으로 읽을 수 있다. 키에 하이픈처럼 변수명 규칙에 맞지 않는 문자가 있거나, 키 이름을 변수로 받아야 한다면 대괄호 표기법을 사용한다.

```js
const student = {
  name: "mj",
  "student-no": 100
};

console.log(student.name);
console.log(student["student-no"]);

student.phone = "010-1111-2222"; // 추가
student.name = "myungji";        // 수정
delete student.phone;             // 삭제
```
