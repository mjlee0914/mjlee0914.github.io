## Streamlit turns Python scripts into interactive apps

I organized my Streamlit practice into two sections: topic-based examples and larger combined exercises. The app explores text output, tables, input widgets, charts, progress indicators, and reusable page layouts.

### What I practiced

- `st.title`, `st.write`, and `st.markdown` for presenting information.
- `st.metric`, `st.dataframe`, `st.table`, and `st.data_editor` for displaying data.
- Buttons, checkboxes, radio buttons, select boxes, and file inputs for collecting user input.
- Tabs, columns, expanders, forms, dialogs, and progress indicators for structuring an app.
- Plotly charts and session state for interactive dashboard behavior.

### Reflection

The main lesson was that small Streamlit calls can be combined into a clear learning flow: organize the screen first, then add widgets that display or collect data. I also saw that a GitHub Pages site can host a static preview, while running the original Python app requires a Streamlit hosting service.
