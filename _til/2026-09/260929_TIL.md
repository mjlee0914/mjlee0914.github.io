## Array Methods — CRUD

**Create**

- `.push()`: 요소를 **끝에 추가**

- `.unshift()`: 요소를 **앞에 추가**
- `.splice(시작, 삭제개수, ...추가요소)`: 지정된 위치에 요소를 **추가하거나 삭제**

```js
const arr = [1, 3];
arr.splice(1, 0, 2);

console.log(arr); // [1, 2, 3]
```

**Read**

- `.forEach(callback)`: 배열의 각 요소를 순회하며 `callback` 실행

```js
const arr = [1, 2, 3];

arr.forEach((value) => {
  console.log(value);
});
```

- `.indexOf()`: 요소의 위치 번호를 **왼쪽 → 오른쪽**으로 검색  
  - 중복값이 있으면 가장 왼쪽 요소의 인덱스 반환

```js
const arr = ["a", "b", "a"];

console.log(arr.indexOf("a")); // 0
```

- `.lastIndexOf()`: 요소의 위치 번호를 **오른쪽 → 왼쪽**으로 검색

```js
const arr = ["a", "b", "a"];

console.log(arr.lastIndexOf("a")); // 2
```

**Update**

- `.map(callback)`: `callback` 결과대로 요소를 변경한 **새 배열 반환**

```js
const arr = [1, 2, 3];

const newArr = arr.map((value) => value * 2);

console.log(newArr); // [2, 4, 6]
```

- `.filter(callback)`: `callback` 조건에 맞는 요소만 골라 **새 배열 반환**

```js
const arr = [1, 2, 3, 4];

const newArr = arr.filter((value) => value > 2);

console.log(newArr); // [3, 4]
```
참고) 접근자 메서드 및 반복 메서드: 원본 유지, 가공값 반환
    - 접근자 메서드: join, slice, concat
    - 반복 메서드: forEach, map, filter, some, every, reduce
**Delete**

- `.pop()`: **끝 요소를 제거**하고 제거한 요소를 반환

```js
const arr = [1, 2, 3];

const value = arr.pop();

console.log(value); // 3
console.log(arr);   // [1, 2]
```

- `.shift()`: **앞 요소를 제거**하고 제거한 요소를 반환

```js
const arr = [1, 2, 3];

const value = arr.shift();

console.log(value); // 1
console.log(arr);   // [2, 3]
```

- `.splice()`: 지정된 위치의 요소를 삭제

```js
const arr = [1, 2, 3];

arr.splice(1, 1);

console.log(arr); // [1, 3]
```
[참고]
Create, Delete -> 원본 데이터 변경
Update -> 새로운 배열 객체 반환
