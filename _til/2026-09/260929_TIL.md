## 실습과제: JavaScript 함수와 배열

오늘은 함수의 매개변수와 정의 방식, 화살표 함수, `this` 바인딩, 스코프 체인과 generator를 공부했다. 이어서 JavaScript 객체의 종류와 배열의 주요 메서드를 살펴보고, 클래스로 전자제품과 스마트폰을 표현하는 실습을 했다.

## 1. 함수의 매개변수

### 매개변수 기본값

함수를 호출할 때 인수를 전달하지 않았거나 해당 인수의 값이 `undefined`이면 매개변수에 기본값을 지정할 수 있다. 기본값이 있는 매개변수는 보통 매개변수 목록 뒤쪽에 둔다.

```js
function add(num1, num2 = 10) {
  return num1 + num2;
}

console.log(add(20));      // 30
console.log(add(20, 5));   // 25
console.log(add(20, undefined)); // 30
```

### `arguments` 객체

일반 함수 안에서는 호출할 때 전달한 인수들을 `arguments` 객체로 확인할 수 있다. 선언한 매개변수 수보다 인수를 더 많이 전달해도 추가 인수는 `arguments`에 남는다.

```js
function sum() {
  let total = 0;

  for (const value of arguments) {
    total += value;
  }

  return total;
}

console.log(sum(10, 20));       // 30
console.log(sum(10, 20, 30));   // 60
```

`arguments`는 배열처럼 순회할 수 있지만 진짜 배열은 아니다. 화살표 함수에는 자체 `arguments`가 없으므로, 전달된 여러 인수를 다룰 때는 나머지 매개변수(`...rest`)를 사용한다.

### 나머지 매개변수(Rest Parameter)

매개변수 앞의 `...`은 나머지 인수들을 새 배열로 모은다. 나머지 매개변수는 반드시 마지막에 와야 한다.

```js
function sum(first, ...rest) {
  return rest.reduce((total, value) => total + value, first);
}

console.log(sum(10, 20, 30, 40)); // 100
```

나머지 매개변수의 `...`은 함수에 전달된 나머지 값을 **모으는** 문법이다. 배열이나 객체를 펼치는 전개 연산자의 `...`과 모양은 같지만 쓰임이 다르다.

## 2. 비구조화 할당과 전개

비구조화 할당은 배열이나 객체의 값을 꺼내 변수에 나누어 담는 문법이다.

```js
const nums = [10, 20, 30, 40];
const [first, , third, ...rest] = nums;

console.log(first); // 10
console.log(third); // 30
console.log(rest);  // [40]
```

객체는 프로퍼티 이름을 기준으로 값을 꺼낸다. 변수 이름을 바꾸려면 `프로퍼티명: 새 변수명` 형태를 쓴다.

```js
const person = { name: "김철수", age: 20 };
const { name: personName, age } = person;

console.log(personName); // 김철수
console.log(age);        // 20
```

전개 연산자는 배열이나 객체의 내용을 펼쳐 새 배열·객체를 만들거나 함수 인수로 전달할 때 사용한다.

```js
const original = [10, 20, 30];
const copied = [...original];

console.log(copied);            // [10, 20, 30]
console.log(copied === original); // false
```

이 복사는 얕은 복사다. 중첩된 객체나 배열이 있다면 그 안쪽 값까지 새로 복사되는 것은 아니다.

## 3. 함수 선언문과 함수 표현식

### 함수 선언문

함수 선언문은 선언 전에 호출할 수 있다. 함수 선언이 평가 단계에서 처리되는 호이스팅 특성 때문이다.

```js
sayHello(); // 안녕하세요!

function sayHello() {
  console.log("안녕하세요!");
}
```

### 함수 표현식

함수 표현식은 함수를 값으로 만들어 변수에 할당한다. `const`나 `let`으로 선언한 변수는 초기화 전에 사용할 수 없으므로, 할당문보다 먼저 호출하면 오류가 난다.

```js
const sayHello = function () {
  console.log("안녕하세요!");
};

sayHello();
```

함수 표현식은 콜백이나 조건에 따라 함수를 값으로 전달할 때 유용하다.

## 4. 화살표 함수

화살표 함수는 함수를 간결하게 표현하는 문법으로, 콜백에 자주 사용한다. 매개변수가 하나면 괄호를 생략할 수 있고, 본문이 한 표현식이면 중괄호와 `return`을 생략할 수 있다.

```js
const square = value => value * value;
console.log(square(5)); // 25
```

화살표 함수에는 일반 함수와 다른 점이 있다.

- `new`를 사용해 생성자 함수로 호출할 수 없다.
- 자체 `arguments` 객체가 없다.
- `yield`를 사용할 수 없다.
- 자체 `this`를 만들지 않고, 바깥 영역의 `this`를 사용한다.

## 5. 일반 함수와 화살표 함수의 `this`

일반 함수의 `this`는 **함수가 어떻게 호출되었는지**에 따라 정해진다. 객체의 메서드로 호출하면 그 객체가 `this`가 된다. 화살표 함수는 호출 방식으로 `this`가 바뀌지 않고, 함수가 만들어진 바깥 영역의 `this`를 그대로 사용한다.

```js
const person = {
  name: "MJ",
  regular() {
    console.log(this.name);
  },
  arrow: () => {
    console.log(this.name);
  }
};

person.regular(); // "MJ": person이 메서드를 호출
```

`arrow`의 `this`는 `person`이 아니다. 객체 리터럴이 `this`의 바깥 함수 영역을 만들지 않기 때문이다. 객체 메서드에는 보통 메서드 축약 문법이나 일반 함수를 사용하고, 바깥 `this`를 이어받아야 하는 콜백에는 화살표 함수가 편리하다.

## 6. 명시적 `this` 바인딩

함수를 호출할 때 `this`를 지정하고 싶으면 `call`, `apply`, `bind`를 사용할 수 있다.

```js
function introduce(city) {
  console.log(`${this.name}은(는) ${city}에 살아요.`);
}

const user = { name: "MJ" };

introduce.call(user, "서울");       // MJ은(는) 서울에 살아요.
introduce.apply(user, ["서울"]);    // 인수를 배열로 전달
const boundIntroduce = introduce.bind(user, "서울");
boundIntroduce();                   // 나중에 실행
```

- `call`: `this`와 인수를 하나씩 전달하고 즉시 실행한다.
- `apply`: `this`와 인수 배열을 전달하고 즉시 실행한다.
- `bind`: 지정한 `this`가 적용된 새 함수를 반환한다. 새 함수는 나중에 호출한다.

## 7. 유효범위 체인과 클로저

함수는 자신이 선언된 위치의 바깥 범위를 단계적으로 살펴 변수를 찾는다. 이 연결을 유효범위 체인(scope chain)이라고 한다. 안쪽 함수는 바깥 함수와 전역 범위의 변수에 접근할 수 있지만, 바깥 함수는 안쪽 함수의 지역 변수에 접근할 수 없다.

```js
const outerValue = "전역 값";

function outer() {
  const innerValue = "outer의 값";

  function inner() {
    console.log(outerValue, innerValue);
  }

  return inner;
}

const savedFunction = outer();
savedFunction(); // 전역 값 outer의 값
```

`outer()` 실행이 끝난 뒤에도 반환된 `inner` 함수가 바깥 변수에 접근할 수 있는 현상을 클로저라고 한다. 클로저는 함수와 그 함수가 기억하는 렉시컬 환경의 조합이다.

## 8. Generator

Generator 함수는 `function*`으로 선언한다. 실행 중 `yield`에서 멈췄다가, 반환된 iterator의 `next()`를 호출하면 다음 `yield`까지 이어서 실행한다.

```js
function* makeNumbers() {
  yield 1;
  yield 2;
  return 3;
}

const iterator = makeNumbers();
console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: 3, done: true }
```

`done`이 `false`이면 이어서 꺼낼 값이 있고, `true`이면 generator 실행이 끝난 것이다. `for...of`는 iterator가 제공하는 값을 순회한다.

## 9. JavaScript 객체의 종류와 `Symbol`

JavaScript 객체는 크게 언어에서 제공하는 native object와 실행 환경이 제공하는 host object로 나눌 수 있다.

- **Native object**: `Object`, `Array`, `String`, `Number`, `Function`, `Date`, `Map`, `Error` 등 JavaScript 표준 객체
- **Host object**: 실행 환경이 제공하는 객체. 브라우저의 `window`, DOM 객체나 Node.js 환경의 기능 등이 예다.

`NaN`은 숫자로 표현할 수 없는 연산 결과를 나타낸다. 값이 `NaN`인지 확인할 때는 전역 `isNaN()`보다 입력을 강제로 변환하지 않는 `Number.isNaN()`을 쓰는 편이 안전하다.

```js
console.log(Number.isNaN(NaN));     // true
console.log(Number.isNaN("hello")); // false
```

`Symbol()`은 고유한 원시 값을 만든다. `Symbol.iterator`는 객체가 반복 가능한지 결정하는 특별한 well-known symbol이다. 배열처럼 iterator를 제공하는 값은 `for...of`로 순회할 수 있다.

```js
const values = ["a", "b"];
console.log(typeof values[Symbol.iterator]); // "function"

for (const value of values) {
  console.log(value);
}
```

## 10. 배열 확인과 주요 메서드

배열은 객체의 한 종류다. `instanceof Array`로 프로토타입 관계를 확인할 수 있고, 배열인지 판별할 때는 `Array.isArray()`가 더 직접적이다.

```js
const values = [1, 2, 3];
console.log(values instanceof Array); // true
console.log(Array.isArray(values));   // true
```

### Create

- `push(value)`: 끝에 요소를 추가한다.
- `unshift(value)`: 앞에 요소를 추가한다.
- `splice(start, deleteCount, ...items)`: 지정 위치의 요소를 삭제하거나 추가한다.

```js
const values = [1, 3];
values.splice(1, 0, 2);
console.log(values); // [1, 2, 3]
```

### Read

- `forEach(callback)`: 각 요소에 대해 콜백을 실행한다. 새 배열을 반환하지 않는다.
- `indexOf(value)`: 왼쪽에서부터 처음 일치하는 값의 인덱스를 찾는다. 없으면 `-1`이다.
- `lastIndexOf(value)`: 오른쪽에서부터 일치하는 값의 인덱스를 찾는다.

```js
const letters = ["a", "b", "a"];
console.log(letters.indexOf("a"));     // 0
console.log(letters.lastIndexOf("a")); // 2
```

### Update / transform

`map(callback)`은 각 요소를 콜백 결과로 바꾼 새 배열을 반환한다. `filter(callback)`은 조건을 통과한 요소만 모은 새 배열을 반환한다. 둘 다 원본 배열을 직접 바꾸지 않는다.

```js
const values = [1, 2, 3, 4];
console.log(values.map(value => value * 2));    // [2, 4, 6, 8]
console.log(values.filter(value => value > 2)); // [3, 4]
console.log(values);                            // [1, 2, 3, 4]
```

### Delete

- `pop()`: 끝 요소를 제거하고 그 값을 반환한다.
- `shift()`: 앞 요소를 제거하고 그 값을 반환한다.
- `splice(start, deleteCount)`: 지정 위치에서 요소를 삭제한다.

`push`, `unshift`, `splice`, `pop`, `shift`는 원본 배열을 변경한다. `join`, `slice`, `concat`, `map`, `filter`, `some`, `every`, `reduce` 등은 원본 배열을 유지하며 결과를 반환한다. 단, `forEach`는 원본을 자동 변경하지 않으며 가공 배열도 반환하지 않는다.

## 실습과제: 클래스 상속으로 스마트폰 만들기

`Electronics` 클래스가 이름과 가격을 보관하고, `Smartphone` 클래스가 이를 상속받아 통신사 정보를 추가한다. 자식 클래스 생성자에서 부모 생성자를 호출할 때는 `super()`를 먼저 실행해야 한다.

```js
class Electronics {
  constructor(name, price) {
    this.name = name;
    this.price = price;
  }

  info() {
    console.log(`product: ${this.name} | price: ${this.price}`);
  }
}

class Smartphone extends Electronics {
  constructor(name, price, telecom) {
    super(name, price);
    this.telecom = telecom;
  }
}

const myPhone = new Smartphone("iPhone", 160, "LG");
myPhone.info(); // product: iPhone | price: 160
console.log(myPhone.telecom); // LG
```

`Smartphone`은 부모 생성자를 통해 `name`, `price`를 이미 가지므로 `smartName`, `smartPrice`라는 중복 프로퍼티를 다시 만들 필요가 없다. `info()`는 `console.log()`만 실행하고 값을 반환하지 않으므로, `console.log(myPhone.info())`처럼 감싸면 정보가 먼저 출력되고 이어서 `undefined`가 출력된다. 메서드의 결과를 화면에 한 번만 출력하려면 `myPhone.info()`로 호출한다.
