## JavaScript in the Browser

JavaScript is a **prototype-based, object-oriented programming language**. In a browser, JavaScript can use both built-in JavaScript objects and **host objects** supplied by the browser environment.

The browser's `window` object is the global object for a page. It provides browser APIs such as `location`, `history`, `navigator`, `screen`, and `document`.

- `location` describes the current URL. Setting `location.href` navigates to another address.
- `history` provides access to session history, such as `history.go(-1)`.
- `navigator` exposes browser and device capabilities, including geolocation.
- `document` represents the current HTML document.

An iframe has its own `window` and `document`. Inside the iframe, `window.parent` refers to the window containing it. Access across origins is restricted by the browser's same-origin policy.

## Objects, Properties, and Methods

A property is a value associated with an object. A method is a function stored as an object property. Dot notation can read either one:

```js
object.property; // read a property value
object.method(); // call a method
```

The parentheses matter: `object.method` refers to the function, while `object.method()` calls it.

## Selecting DOM Elements

The `document` object provides methods for finding elements in the HTML document. For example, `getElementById()` returns one element, while `querySelectorAll()` returns all elements matching a CSS selector.

```js
const firstMenu = document.querySelector(".menu");
const allMenus = document.querySelectorAll(".menu");

console.log(firstMenu.textContent);
console.log(allMenus.length);
```

Some DOM collections, such as the result of `getElementsByClassName()`, are **array-like objects**. They have numeric indexes and a `length` property, but they are not real arrays and do not necessarily have array methods such as `map()`.

```js
const menuCollection = document.getElementsByClassName("menu");
console.log(menuCollection[0]);
console.log(menuCollection.length);

const menuArray = Array.from(menuCollection);
```

`querySelectorAll()` returns a `NodeList`; `getElementsByClassName()` returns an `HTMLCollection`. Both can be iterated, but converting a collection with `Array.from()` is useful when array methods are needed.

## Attributes, Properties, and `data-*`

HTML attributes are written in markup. DOM elements also expose JavaScript properties. They often correspond, but they are not identical in every case. Use `getAttribute()` and `setAttribute()` when you specifically need to work with an HTML attribute.

For extra application data, HTML supports custom `data-*` attributes. Read and update them through the selected element's `dataset` property (not `document.dataset`):

```html
<button id="add-item" data-category="study" data-item-id="42">Add</button>
```

```js
const button = document.querySelector("#add-item");
console.log(button.dataset.category); // "study"
console.log(button.dataset.itemId);  // "42"

button.dataset.category = "work";
delete button.dataset.itemId;
```

The `data-` prefix is omitted in JavaScript, and dashed names become camelCase. These attributes store extra information without using built-in attributes such as `type` for an unrelated purpose.

## Changing Classes

`classList` provides methods for working with an element's classes. `contains()` checks for a class, while `add()` and `remove()` update it. `toggle()` is a concise way to switch a class on and off.

```js
const card = document.querySelector(".card");
card.classList.toggle("is-active");
```

In the lecture example, clicking a button toggles a class on a photo container. CSS uses that class to hide one image and show another. This separates the interaction (JavaScript) from the presentation (CSS).
