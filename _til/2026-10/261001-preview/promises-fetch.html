Callbacks, Promises, Async/Await, and Fetch

Each button runs the same three dependent jobs in order.

Callback nesting

work("A", 500, function (a) {
  work("B", 350, function (b) {
    work("C", 250, function (c) {
      console.log(a, b, c);
    });
  });
});

Promise chain

work("A", 500)
  .then(function (a) {
    return work("B", 350).then(function (b) {
      return [a, b];
    });
  })
  .then(function (results) {
    return work("C", 250).then(function (c) {
      console.log(results[0], results[1], c);
    });
  })
  .catch(function (error) {
    console.error(error);
  });

Async/await

async function execute() {
  const a = await work("A", 500);
  const b = await work("B", 350);
  const c = await work("C", 250);
  console.log(a, b, c);
}

AJAX with Fetch

Fetch one JSON record and display the response as text.


The remote request has not run yet. 
const response = await fetch(url);
if (!response.ok) {
  throw new Error("HTTP " + response.status);
}
const data = await response.json();
output.textContent = JSON.stringify(data, null, 2);
fetch(url)
  .then(function (response) { return response.text(); })
  .then(function (text) {
    output.textContent = text;
  });

The demo needs a network connection. Fetch also requires checking response.ok because HTTP error statuses do not by themselves reject its Promise.
