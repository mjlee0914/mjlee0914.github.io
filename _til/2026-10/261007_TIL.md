---

JSX(JavsScript XML), TSX(TypeScript XML)

1. `<div> ... </div>`
2. 단일 태크 JSX -> 반드시 끝맺음 기호 필수 `<br />`
3. (....)에 JSX 객체 정의
4. 컴포넌트는 단일 노드로 구성 (가상 DOM과의 차이 감지 속도 향상, TSX->React.createElement()변환 시 함수는 하나의 객체만 반환하므로 최상위 태그는 반드시 하나)
   -> 출력을 하지 않는 단일 컴포넌트 `<Fragment>`
5. JSX 문법 구간 (...)에 자바스크립트 코드 사용하는 경우 {....} 작성
6. 조건식
   1. 삼항 연산자 `condition ? true: false`
   2. && 연산자(단락회로평가):조건이 true여야만 뒤의 요소를 화면에 출력, false -> 평가 중단 및 아무것도 표시 x
7. 주석

- `{ /* ... */ }` : 여러줄
- `{ // .... 줄개행}`: 한줄 주석, 줄개행 필수

8. 반환값
   - `React.JSX.Element`: JSX 요소만 반환(HTML tag 형태)
   - `React.ReactNode`: JSX 요소 + 다른 형태의 값 (문자열, 숫자, null, function, obj, ...), 더 넓은 범위

A component = js function

- takes props, just like a function takes arguments
- returns react elements
  - react elements: JSX tags

```tsx

function Button({ label, color }) {
  return  (
    <button
    style={{ background: color }}
    >
    {label}
    </button>;
);
}
```

- this Button function can be adpated into sevearl buttons like order btn, add to wishlist btn, and checkout btn.
- one component, several buttons
- function is like a blueprint
- one components will be reusable

```tsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0); // array destructuring

  return <button onClick={() => setCount(count + 1)}>Count: {count}</button>;
}
```

- state is for when the screen updates the changed data
- `count` as current value
- `setCount` : a state setter function
  - when it's called, React schedules re-render
  - and it runs component function again
  - differing what changed and what not
  - updates only what's changed
- so each time button is clicked(by onClick), count+1

diffing

- when the state changes, React updates the Virtual DOM
- applies only those changed.
- React differentiate Virtual DOM and Real DOM. = Diffing
