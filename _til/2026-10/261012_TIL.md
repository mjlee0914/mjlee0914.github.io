`use client`

- Next.js App Router에서 onClick, onChange 등 브라우저 이벤트를 포함한 컴포넌트 파일 최상단에 반드시 선언

리액트 컴포넌트에서 여는 태그와 닫는 태그 사이(<Card>내용</Card>)에 들어간 내용을 전달받을 때 사용하는 특별한 Props의 이름과 그 타입으로 올바른 것은?

- props 이름: children, 타입: React.ReactNode
- children은 태그 사이에 포함된 내용을 전달받는 리액트의 약속된 특별한 Prop이며, 글자·HTML 태그·다른 컴포넌트 등 무엇이든 올 수 있으므로 TypeScript에서는 React.ReactNode 타입을 사용합니다.

배열 인덱스 vs 고유 id ex) `crypto.randomUUID()`

- 배열 인덱스의 경우 리액트 리스트 렌더링에서 항목의 추가, 삭제, 순서 변경 시 값이 바뀌어 상태 관리 오류를 유발할 수 있어 key로 사용하는 것이 권장되지 않음
- 배열 인덱스는 리스트 항목의 순서가 바뀌면 값도 함께 바뀌므로, 이를 key로 사용하면 리액트가 이전 상태와 잘못 비교하여 UI 오류를 일으킬 수 있음
- 반면 고유 id는 데이터가 변경되어도 값이 유지되어 안전

`useCallback`

```tsx
const onSubmit = useCallback(
  (e) => {
    // ...
  },
  [form],
);
```

- `useCallback` asks React to keep the same onSubmit function while form stays the same. When form changes, React gives it an updated function so it sees your latest typed text.

Ajax(Asynchronous JavaScript and XML)는 웹 페이지 전체를 새로고침하지 않고, 백그라운드에서 서버와 데이터를 주고받아 페이지의 일부분만 동적으로 갱신하는 웹 개발 기법

- `<a href="/login">` starts a full browser navigation. The browser requests a new HTML document, builds its DOM, and fires DOMContentLoaded.
- `<Link href="/login">` does a client-side navigation. Next may fetch the route’s data (or already have prefetched it), then updates the current page’s DOM. There’s no new document, so there’s no new DOMContentLoaded event. --> Next updates the existing DOM, The DOM is still updated
  https://nextjs.org/docs/app/getting-started/linking-and-navigating
