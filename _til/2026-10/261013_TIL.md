## Today's Project

I worked on the home page and shared layout for the [FE-project-teamD repository](https://github.com/mjlee0914/FE-project-teamD). The page uses Next.js App Router, React components, TypeScript, and Tailwind CSS.

The source reference is commit [`7a87391`](https://github.com/mjlee0914/FE-project-teamD/commit/7a87391). The snapshot and notes below also reflect the three local working-tree edits present on October 13: `MainBanner.tsx`, `ProductCard.tsx`, and `shared/mocks/mockData.ts`.

## Home Page and Shared Layout

The home route, `app/(shop)/page.tsx`, composes the page from three domain components in order: `MainBanner`, `PopularProducts`, and `EventBanner`. The root layout in `app/layout.tsx` places the shared `Header` above the route content and the shared `Footer` below it.

- **Header — `shared/components/Header.tsx`:** added the DN Mall brand link, product/search/cart/login controls, and a second row of category links.
- **Footer — `shared/components/Footer.tsx`:** grouped company information, customer support details, and board shortcuts into responsive columns, followed by the project copyright line.

## Home Domain Components

- **`MainBanner.tsx`:** displays the main campaign image, a dark overlay, headline and supporting text, and a “SHOP NOW” button. The current local version also defines a `human` interface and a typed `AX_PEOPLE` sample array.
- **`PopularProducts.tsx`:** selects three entries from `MOCK_PRODUCTS` and passes them to `ProductGrid`.
- **`ProductGrid.tsx`:** renders product cards in a responsive grid and provides an empty-state message when there are no products.
- **`ProductCard.tsx`:** shows each product image, name, HOT label, and formatted price. The current local edit renders the `next/image` image inside the product-detail link.
- **`EventBanner.tsx`:** presents three promotions with their own image and call-to-action button.
- **Home assets:** `mainbanner.png` supplies the hero; `clothes.png`, `blackfriday.png`, and `sneakers.png` supply the three event cards.
- **`shared/mocks/mockData.ts`:** includes the current local `Product` interface used to type the mock product list.

This work keeps the route responsible for page order, shared components responsible for site-wide navigation and footer content, and the home domain components responsible for the page sections.
