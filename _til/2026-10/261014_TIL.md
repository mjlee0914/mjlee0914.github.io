## Today's Project: Shared UI Components

My assigned area is the reusable component layer in [`shared/components/ui`](https://github.com/mjlee0914/FE-project-teamD/tree/main/shared/components/ui). I reviewed and worked with six components in the project snapshot at commit [`06c366f`](https://github.com/mjlee0914/FE-project-teamD/commit/06c366f). These small building blocks give pages a consistent look and let other components reuse common controls.

- **`button.tsx` — Button:** wraps Base UI's Button primitive. `class-variance-authority` (`cva`) defines visual variants such as `default`, `outline`, `secondary`, `ghost`, `destructive`, and `link`, along with sizes from `xs` to `icon-lg`. `VariantProps` keeps those choices typed, and `cn` combines the generated classes with a caller's `className`.
- **`badge.tsx` — Badge:** creates compact labels such as status chips. It uses `cva` for visual variants and Base UI's `useRender` with `mergeProps` so callers can customize the rendered element while retaining the shared styling and props.
- **`card.tsx` — Card:** provides composable pieces: `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, and `CardFooter`. Data-slot attributes let the Tailwind styles adjust spacing and borders based on which pieces are present; `Card` also supports default and small sizes.
- **`dialog.tsx` — Dialog:** wraps Base UI's dialog parts for the root, trigger, portal, overlay, content, title, description, and close action. The shared content includes an optional close button, and the file is a client component because the dialog is interactive.
- **`dropdown-menu.tsx` — Dropdown Menu:** composes Base UI menu parts for triggers, positioned content, groups, labels, regular and destructive items, checkboxes, radio choices, submenus, separators, and keyboard shortcuts.
- **`input.tsx` — Input:** wraps Base UI's input and keeps the standard React input props. Its shared classes define the height, border, placeholder, focus, invalid, and disabled states.

Across these files, `data-slot` names identify each component part, while Tailwind classes keep its default appearance and interaction states together. The shared components can then be assembled into page-specific interfaces without repeating their base styles.

오늘은 팀장님이 결석하셔서 얼떨결에 부팀장(?)이 됐다. 내가 괜히 너무 나선 건 아닌지 쓸데없는 걱정 중.

우리 팀은 나를 포함해 I 성향이 강한 편이라, 오전 회의가 끝나고 특별한 일이 없으면 서로 말을 많이 하지는 않는다. 그래도 다들 묵묵히 자기 일을 잘한다. “이거 어디까지 하셨어요?” 하고 여쭤보면 하나만 해도 되는데 벌써 다섯 개를 다 하신 경우도 있다. 다들 척척 진행하는 모습이 신기하다. 서로 성향이 잘 맞아서인지, 좋은 팀원들을 만나서인지!

팀 활동도 실제 취업 전에 경험하는 사회생활의 일부라고 생각한다. 좋은 게 좋은 거라는 마음으로, 튜터님이 해주신 말씀처럼 낙담시키는 말들은 한 귀로 듣고 한 귀로 흘려보내야지.

항상 스스로 되새길 말: 나부터 잘하자. 겸손 최고.
