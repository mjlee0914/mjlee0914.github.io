## Today's Project Update: FE-project-teamD `main`

I checked the latest `main` branch at commit [`571ca8e`](https://github.com/mjlee0914/FE-project-teamD/commit/571ca8e5f8d50959ef8776995bc8410b42af4242) and compared it with yesterday's project snapshot at [`06c366f`](https://github.com/mjlee0914/FE-project-teamD/commit/06c366fe71e48ce50f90f7047dde6fdd745acf34). The main branch now brings together the home-page work and several merged shopping, board, and admin flows.

### Home page and category updates

The home route composes `MainBanner`, `PopularProducts`, and `EventBanner`. The popular-products section sorts the mock products by view count and displays the three most-viewed items. The event section now reads event posts from mock data and presents them in a Swiper carousel with autoplay, navigation arrows, and responsive layouts for one, two, or three slides.

The latest main commits also update the mock category labels and order. The top-level list now starts with **Best**, followed by **Tops & Sweaters**, **Pants & Jeans**, **Dress & Skirt**, **Shoes & Bags**, and **Sale**. The category data stays in `MOCK_CATEGORY_ROWS` and is organized into a tree for the category navigation.

### Other work now in `main`

- **Boards:** event pages and post detail routes are in place, with create, edit, and delete flows, form validation, and permission checks.
- **Shopping:** the product detail and cart flows have been expanded, and checkout now leads to an order-completion page.
- **Admin:** category, product, and order pages include tables and editing dialogs for managing the mock shop data.

These changes make more of the shopping flow visible in the project. The catalog and event examples still use mock data, so the preview below is a snapshot of the main page rather than a live transaction flow.

## Reflection

오늘은 ‘좋은 게 좋은 거다’라는 마음으로 팀 내부의 소통 방식을 돌아봤다. 코드를 작성하다 오류가 생겼을 때 그냥 두면 영원히 해결되지 않듯, 팀 프로젝트에서도 무언가 어긋났을 때 해결하지 않고 넘기면 계속 남는다. 한 번 하는 프로젝트지만 나를 위해, 그리고 우리 팀을 위해 지금 해결할 수 있는 일은 해결하고 넘어가야겠다.

팀원 한 명이 코딩을 아무리 잘하더라도 소통이 되지 않으면 좋은 결과물을 만들기 어렵다고 생각한다. 작은 습관부터 쌓자. 하루에 노션 학습 자료를 한 페이지씩 읽고, 너무 길면 한 섹션씩이라도 읽자. 내가 다른 사람도 이해하기 쉽게 설명할 수 있을 정도로 이해하는 것을 목표로 하겠다.

**Being optimistic is my talisman.**
