Synchronous, Asynchronous, and the Event Loop

JavaScript runs the current task to completion. Timer callbacks and Promise handlers wait in queues until the current stack is clear.

Call stack

Run the current synchronous JavaScript here, one step at a time.

Browser APIs

Timers and network operations wait outside the call stack. When ready, they queue work.

See the order

Promise.then() → microtasksetTimeout() → task
The log will show the order. 
console.log("sync start");

setTimeout(function () {
  console.log("timer task");
}, 0);

Promise.resolve().then(function () {
  console.log("Promise microtask");
});

console.log("sync end");
